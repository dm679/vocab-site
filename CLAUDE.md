# Словарики учеников по английскому

Каждый ученик = отдельная папка с файлом `words.json`. Страницы собираются автоматически
(`build.py` + `template.html`) и публикуются на GitHub Pages после каждого push в `main`
(~1 минута). Ссылки постоянные, не менять папки и `students.json` без просьбы.

| Ученик (название чата) | Файл | Ссылка для ребёнка |
|---|---|---|
| Даша | `dasha-k7p2/words.json` | https://dm679.github.io/vocab-site/dasha-k7p2/ |
| Илья | `ilya-m3x9/words.json` | https://dm679.github.io/vocab-site/ilya-m3x9/ |
| Лера | `lera-q8w4/words.json` | https://dm679.github.io/vocab-site/lera-q8w4/ |

Ученика определяй по названию чата (или по имени в сообщении). Если непонятно — спроси.

## Как добавлять слова
1. `git pull`, открой `words.json` нужного ученика.
2. Добавь новые слова В КОНЕЦ массива, старые не трогай. Формат одной записи:
   `{"word": "apple", "pos": "n", "ipa": "[ˈæp.əl]", "tr": "яблоко"}`
3. Проверь, что JSON валиден: `python3 build.py` (должен вывести число слов).
4. `git commit` и `git push` в `main`. Через минуту слова появятся по ссылке.

## Правила
- `ipa` — британская транскрипция IPA в квадратных скобках.
- `tr` — перевод, 1–2 основных значения. Если указан контекст/значение — бери его.
- `pos` — одно из: n, v, adj, adv, prep, pron, conj, num, phr (фраза), i (идиома).
  Если часть речи не указана и их несколько — бери самую частую и скажи об этом.
- Слово уже есть — не дублируй, сообщи.
- Опечатка — добавь правильное написание и отметь это в ответе.
- Ответ короткий: «Добавлено: 12. apple (n) [ˈæp.əl] — яблоко».
- Не добавляй фамилии, фото и другие личные данные детей.
